Buzzword support

Questions, bugs and rule fixes all go to GitHub.

The fastest way to get help is to open an issue on the Buzzword GitHub page. You'll need a free GitHub account.

Open an issue on GitHub

What to include

  • What you clicked (Check whole story or Check selection) and what happened.
  • For a wrong or missing rule: the card title or suggestion, and the sentence it was about.
  • Your Chrome version, if something didn't load.

Don't paste unpublished stories into a public issue. GitHub issues are public. Change the names or rewrite the sentence so it shows the same problem.

Common questions

I don't see the bee. Buzzword only appears on Google Docs documents. Reload the doc after installing. It checks the story body of The B's Article Draft template, between the "Article Draft" heading and the "Otter link + Notes" section.

A suggestion I rejected came back. It shouldn't. Please open an issue with the rule name.

How do I remove everything Buzzword saved? Remove the extension from Chrome. See the privacy policy for what it saves.
